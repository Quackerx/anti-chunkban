- This mod prevents you from getting chunkbanned. Works on all minecraft servers. 
- This mod can NOT prevent server side chunkbans like "Packet too large: size " + bodyLength + " is over 8".
- This mod CAN create chunkbans, as I have added 4 buttons:
1. Auto drop
2. Auto Sign
3. Fill (Fills the book with data, around 75KB)
4. Activate or deactivate the mod (Button in inventory)
  
- Please report any issues or if there are any new chunkbans / bookbans that I should be aware of.

- Download the built version from *https://modrinth.com/mod/anti-chunkbans*
